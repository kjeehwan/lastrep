# Notebook Fonts

Static TrueType fonts from Adobe's official repositories, bundled locally for
Workout. No font downloads occur at runtime. Static instances avoid the thin
variable-font default observed in the Android device check.

- source-sans-3.ttf: SourceSans3-Regular.ttf
- source-sans-3-semibold.ttf: SourceSans3-Semibold.ttf
- source-serif-4.ttf: SourceSerif4-Semibold.ttf

Sources:
https://github.com/adobe-fonts/source-sans/tree/release/TTF
https://github.com/adobe-fonts/source-serif/tree/release/TTF

SIL Open Font License notices are included beside the fonts. Browser mockups keep
their original variable fonts; native fonts have the same families and intended
weights, not the variable files' platform-specific default weight.
